# Броня ящеров — зафиксированная визуальная спецификация

## Обычный тяжёлый комплект

- Материал: зелёные пластины/чешуя ящеров, тёмная подкладка, светлые костяные шипы.
- Самоцветов, осколков и магического свечения нет.
- На каждом ботинке ровно три передних костяных когтя: левый, центральный и правый.
- Три когтя должны читаться и на модели персонажа, а не только на иконке предмета.

Эталон: `stone_fang_heavy_turnaround.png`.

## Возвышенный тяжёлый комплект

Расположение вставок является фиксированным:

1. Нагрудник — один цельный овальный самоцвет строго по центру груди.
2. Шлем — один осколок строго по центру лобной пластины.
3. Поножи — один осколок строго по центру пояса.
4. Ботинки — по одному осколку на передней верхней части каждого ботинка.

На плечах, руках, кистях, бёдрах, коленях, боковых и задних пластинах вставок нет. На каждом ботинке остаются три костяных когтя.

Эталон геометрии: `firstfang_heavy_turnaround.png`.

## Анимация ядовитой ауры

- Анимируются только пять вставок: самоцвет груди и четыре осколка.
- Зелёное ядро каждой вставки остаётся неподвижным; меняется отдельный фиолетово-пурпурный слой ауры.
- Фиолетовая аура обозначает ядовитую природу босса и биома.
- Цикл состоит из восьми кадров и должен быть бесшовным:
  1. почти погасшая аура;
  2. тонкий фиолетовый обод;
  3. появление искр;
  4. расширение свечения;
  5. максимальная ядовитая вспышка;
  6. сжатие дуг;
  7. затухающие частицы;
  8. возврат к почти погасшему состоянию первого кадра.
- Геометрия брони, положение вставок и поза между кадрами не меняются.
- Рекомендуемый игровой рендер: базовая непрозрачная текстура брони плюс отдельная анимированная emissive/translucent-маска ауры. Это позволит свечению оставаться заметным ночью и не перекрашивать зелёные пластины.

Эталон фаз: `firstfang_poison_aura_8_frames.png`.
